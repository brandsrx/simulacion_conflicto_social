Contexto del Proyecto

Justificación académica, problemática real y alcance de la simulación numérica.

¿Por qué este proyecto?

En un contexto de crisis socioeconómica, los efectos se propagan en cadena: la escasez de combustible paraliza el transporte, lo cual interrumpe las cadenas de suministro alimentario, provocando aumentos de precios que erosionan el poder adquisitivo de las familias. Paralelamente, los rumores y la desinformación generan compras de pánico, agravando la escasez real.

Este proyecto demuestra cómo los métodos numéricos pueden modelar cada uno de estos fenómenos y proporcionar herramientas cuantitativas para la toma de decisiones.

A diferencia de un ejercicio teórico, este proyecto aplica cada método numérico a un escenario concreto y relevante, mostrando el poder real de las matemáticas computacionales.

Escenarios Simulados

Escenario A — Distribución de Suministros

Sistemas lineales para optimizar el flujo de recursos a través de redes de transporte entre ciudades.

Escenario B — Agotamiento de Combustible

Ecuaciones diferenciales para modelar la disminución de reservas con consumo variable y suministro reducido.

Escenario C — Curvas de Precios

Interpolación para reconstruir y predecir la evolución de precios de alimentos básicos con datos incompletos.

Escenario D — Costos Acumulados

Integración numérica para cuantificar el impacto económico total sobre las familias durante la crisis.

Escenario E — Umbrales Críticos

Raíces de ecuaciones para determinar los puntos de quiebre en reservas, precios y demanda.

Escenario F — Rumores y Pánico

Sistemas lineales para modelar la propagación de información falsa entre zonas urbanas.

Escenario G — Descontento Social

Modelo SIR resuelto con ecuaciones diferenciales para simular la difusión del descontento.
