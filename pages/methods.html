Sistemas de Ecuaciones Lineales

Resolución de Ax = b con métodos directos e iterativos

Descomposición LU

Método directo que factoriza A = LU. Resuelve sistemas con sustitución hacia adelante y hacia atrás. Complejidad O(n³/3).

A = LU → Ly = b → Ux = y

Método de Jacobi

Método iterativo que actualiza todas las incógnitas simultáneamente usando los valores de la iteración anterior.

xᵢ⁽ᵏ⁺¹⁾ = (bᵢ - Σⱼ≠ᵢ aᵢⱼxⱼ⁽ᵏ⁾) / aᵢᵢ

Gauss-Seidel

Mejora de Jacobi: usa valores actualizados inmediatamente. Converge más rápido para matrices diagonalmente dominantes.

xᵢ⁽ᵏ⁺¹⁾ = (bᵢ - Σⱼ<ᵢ aᵢⱼxⱼ⁽ᵏ⁺¹⁾ - Σⱼ>ᵢ aᵢⱼxⱼ⁽ᵏ⁾) / aᵢᵢ

SOR

Successive Over-Relaxation. Acelera Gauss-Seidel con un factor de relajación ω. Óptimo para 1 < ω < 2.

xᵢ = (1-ω)xᵢ⁽ᵏ⁾ + ω·(GS update)

Gradiente Conjugado

Método óptimo para matrices simétricas definidas positivas. Converge en a lo sumo n iteraciones.

pₖ₊₁ = rₖ₊₁ + βₖpₖ

Raíces de Ecuaciones

Encontrar x tal que f(x) = 0

Bisección

Divide el intervalo por la mitad en cada iteración. Convergencia garantizada pero lenta (lineal). Robusto y confiable.

c = (a+b)/2, error ≤ (b-a)/2ⁿ

Newton-Raphson

Usa tangentes para aproximar la raíz. Convergencia cuadrática cerca de la raíz. Requiere la derivada f'(x).

xₙ₊₁ = xₙ - f(xₙ)/f'(xₙ)

Secante

Aproxima la derivada con diferencias finitas. No requiere f'(x). Convergencia superlineal (orden ≈ 1.618).

xₙ₊₁ = xₙ - f(xₙ)·(xₙ-xₙ₋₁)/(f(xₙ)-f(xₙ₋₁))

Interpolación

Construir funciones que pasen por puntos dados

Lagrange

Construye el polinomio interpolante usando la fórmula de polinomios base de Lagrange. Directo pero costoso para muchos puntos.

P(x) = Σᵢ yᵢ·Lᵢ(x)

Newton (Dif. Divididas)

Usa una tabla de diferencias divididas. Eficiente para agregar puntos incrementalmente.

P(x) = f[x₀] + f[x₀,x₁](x-x₀) + ...

Splines Cúbicos

Polinomios cúbicos por tramos con continuidad C². Evita oscilaciones de Runge. Ideal para datos reales.

Sᵢ(x) = aᵢ + bᵢ(x-xᵢ) + cᵢ(x-xᵢ)² + dᵢ(x-xᵢ)³

Integración Numérica

Calcular ∫f(x)dx numéricamente

Regla del Trapecio

Aproxima el área con trapecios. Simple y robusto. Error O(h²).

∫ ≈ h/2 · [f(x₀) + 2f(x₁) + ... + f(xₙ)]

Simpson 1/3

Usa parábolas para aproximar. Requiere número par de subintervalos. Error O(h⁴).

∫ ≈ h/3 · [f(x₀) + 4f(x₁) + 2f(x₂) + ...]

Simpson 3/8

Usa polinomios cúbicos. Requiere subintervalos múltiplos de 3. Error O(h⁴).

∫ ≈ 3h/8 · [f(x₀) + 3f(x₁) + 3f(x₂) + 2f(x₃) + ...]

Ecuaciones Diferenciales

Resolver dy/dt = f(t,y) numéricamente

Euler

El método más simple. Usa la pendiente en el punto actual. Error O(h). Puede ser inestable con pasos grandes.

yₙ₊₁ = yₙ + h·f(tₙ, yₙ)

Heun (Euler Mejorado)

Predictor-corrector: promedia pendientes del inicio y fin del intervalo. Error O(h²).

yₙ₊₁ = yₙ + h/2·[f(tₙ,yₙ) + f(tₙ₊₁,ỹₙ₊₁)]

Runge-Kutta 4

El estándar de oro. Usa 4 evaluaciones de f por paso para lograr error O(h⁴). Excelente balance precisión-costo.

yₙ₊₁ = yₙ + h/6·(k₁ + 2k₂ + 2k₃ + k₄)
